# Tech Tools

Herramientas de optimización, limpieza y mantenimiento de Windows, presentadas en una interfaz estilo PowerShell.

## Características

- Catálogo de herramientas de Windows organizadas por categorías
- Reproductor de YouTube integrado
- Autocompletado de comandos
- Diseño responsive (móvil y escritorio)

## Uso

Abrí `index.html` en tu navegador o visitá la [página en vivo](https://TU-USUARIO.github.io/tech-tools/).

### Comandos disponibles

| Comando | Descripción |
|---------|-------------|
| `music "url"` | Reproduce un video de YouTube |
| `add "url"` | Agrega un video a la cola |
| `play` / `pause` | Reanuda / Pausa |
| `next` / `prev` | Siguiente / Anterior |
| `shuffle` | Aleatorio ON/OFF |
| `loop` | Repetir ON/OFF |
| `queue` | Ver cola de reproducción |
| `volume [0-100]` | Ajustar volumen |
| `clear` | Limpiar pantalla |
| `help` | Ver comandos |

También podés escribir el nombre de una herramienta (ej: `sophia`, `bleachbit`) para abrir directamente su enlace.
