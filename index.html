WINDOWS TOOLS

[ACTIVACION]

├─ Massgravel

Activa Windows y Office. Script open source, muy conocido.

→ https://github.com/massgravel/Microsoft-Activation-Scripts

[RUNTIMES]

└─ Install-Runtimes

Te instala los runtimes que piden los juegos/programas (Visual C++, .NET, etc).

→ https://github.com/BEF172/Install-Runtimes

[OPTIMIZACION]

├─ Sophia Script

El mas completo. Debloat, tweaks, personalizacion. Para Win10/11.

→ https://github.com/Sophia-Community/SophiApp

├─ WinScript

GUI moderna. Debloat + instalar programas + tweaks. Bastante seguro.

→ https://github.com/flick9000/winscript

├─ Winhance

Parecido a Sophia pero con interfaz grafica. Bueno para Win10/11.

→ https://github.com/memstechtips/Winhance

├─ Chris Titus WinUtil

Muy conocido. Tweaks, software, WU, reparacion. Todo en uno.

→ https://github.com/ChrisTitusTech/winutil

└─ ThisIsWin11

Dice Win11 pero varias cosas sirven en Win10 tambien.

→ https://github.com/builtbybel/ThisIsWin11

[LIMPIEZA]

├─ BleachBit

Limpia caché, temporales, navegadores. El CCleaner pero libre.

→ https://www.bleachbit.org/

└─ BCUninstaller

Desinstala todo, incluso lo que Windows no deja. Apps UWP, restos del registro, etc.

→ https://www.kcsoftwares.com/?q=bcuninstaller

[DRIVERS]

└─ Snappy Driver Origin

Instala drivers sin depender de Windows Update. Muy util despues de formatear.

→ https://sdi-tool.org/

[DIAGNOSTICO]

├─ WinDirStat

Te muestra que ocupa espacio en el disco, como un mapa visual.

→ https://windirstat.net/

├─ WizTree

Lo mismo que WinDirStat pero mas rapido. No es open source.

→ https://diskanalyzer.com/

├─ CrystalDiskInfo

Revisa el estado SMART del disco. Si esta fallando, lo ves ahi.

→ https://crystalmark.info/en/software/crystaldiskinfo/

└─ OCCT

Stress test para CPU, GPU y RAM. Sirve para probar estabilidad.

→ https://www.ocbase.com/

[HERRAMIENTAS TODO EN UNO]

├─ Hiren's Boot CD

Suite de rescue boot. Particionado, clonacion, recovery, antivirus offline. Indispensable para tener en un USB.

→ https://www.hirensbootcd.org/

└─ Medicat

Basado en Hiren's pero actualizado y con mas herramientas. Incluye VPN, navegadores, etc.

→ https://medicatusb.com/

[PREPARAR ISO]

├─ Ventoy

Copias las ISOs a un USB y booteas desde cualquiera. Sin formatear cada vez.

→ https://www.ventoy.net/

└─ Rufus

El clasico para crear booteables. Soporta Windows, Linux, UEFI/BIOS.

→ https://rufus.ie/

[PAQUETES]

└─ UniGetUI

GUI para WinGet, Scoop, Chocolatey, Pip, NPM. Instalas un monton de cosas de una.

→ https://marticliment.com/unigetui/
