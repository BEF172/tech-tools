WINDOWS TOOLS - Herramientas

[🛠️ ACTIVACION]

├─ Massgravel

Script de PowerShell Para activar Aplicaciones/S.O de Windows.

→ https://github.com/massgravel/Microsoft-Activation-Scripts

[💿 RUNTIMES]

└─ Install-Runtimes

Script de PowerShell para instalar automáticamente los runtimes necesarios (Visual C++, .NET, etc.).

→ https://github.com/BEF172/Install-Runtimes

[🛠️ OPTIMIZACIÓN]

├─ Sophia Script

Script de PowerShell muy completo para debloat, tweaks y personalización de Windows 10/11.

→ https://github.com/Sophia-Community/SophiApp

├─ WinScript

Interfaz gráfica moderna. Debloat. Instalar programas. Optimización de Windows. Bastante seguro.

→ https://github.com/flick9000/winscript

├─ Winhance

Muy parecido a Sophia. Muchas opciones con interfaz gráfica. Ideal para Windows 10/11.

→ https://github.com/memstechtips/Winhance

├─ Chris Titus Tech WinUtil

Uno de los más populares. Debloat, software, tweaks, Windows Update, reparación.

→ https://github.com/ChrisTitusTech/winutil

└─ ThisIsWin11

Aunque dice Windows 11, varias funciones sirven para Windows 10.

→ https://github.com/builtbybel/ThisIsWin11

[🧹 LIMPIEZA]

├─ BleachBit

Código abierto. Limpia caché, temporales, navegadores, logs. Alternativa libre a CCleaner.

→ https://www.bleachbit.org/

└─ Bulk Crap Uninstaller (BCUninstaller)

Desinstala programas difíciles, apps UWP, restos del registro. Muy recomendable.

→ https://www.kcsoftwares.com/?q=bcuninstaller

[⚙️ DRIVERS]

└─ Snappy Driver Installer Origin

Proyecto libre para instalar drivers sin depender de Windows Update. Ideal después de formatear.

→ https://sdi-tool.org/

[🔍 DIAGNÓSTICO]

├─ WinDirStat

Muestra visualmente qué ocupa espacio en disco.

→ https://windirstat.net/

├─ WizTree

No es open source, pero es el más rápido para analizar espacio.

→ https://diskanalyzer.com/

├─ CrystalDiskInfo

Para revisar el estado SMART del SSD/HDD.

→ https://crystalmark.info/en/software/crystaldiskinfo/

└─ OCCT

Para probar estabilidad del hardware (CPU, GPU, RAM).

→ https://www.ocbase.com/

[🔧 SYSINTERNALS (Microsoft)]

Si te gusta tocar Windows, esta colección es imprescindible.

├─ Autoruns

├─ Process Explorer

├─ Process Monitor

├─ RAMMap

├─ TCPView

└─ PsTools

→ https://learn.microsoft.com/en-us/sysinternals/downloads/

[🎮 GAMING]

├─ ParkControl

Controla el Core Parking de CPU.

→ https://bitsum.com/parkcontrol/

├─ MSI Utility v3

Permite activar MSI Mode en dispositivos PCIe. Solo si sabés lo que hacés.

└─ ISLC (Intelligent Standby List Cleaner)

Muy usado para reducir stuttering en algunos juegos.

→ https://www.wagnardsoft.com/forums/viewtopic.php?t=12009

[📦 ADMINISTRADORES DE PAQUETES]

└─ UniGetUI

Interfaz gráfica para WinGet, Scoop, Chocolatey, Pip, NPM. Instalá cientos de programas con un clic.

→ https://marticliment.com/unigetui/
